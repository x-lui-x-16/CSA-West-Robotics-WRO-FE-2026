# 🚗 Rear-Wheel Drive (RWD) System
The robot uses a rear-wheel drive layout: the LEGO EV3 Large Motor powers a rigid rear axle, while steering is handled separately by the front wheels. Separating drive and steering keeps the mechanics simple and improves predictability, since each wheel pair only has one job.

This layout also simplifies the chassis design, since the drivetrain doesn't need to move with the steering linkage.
