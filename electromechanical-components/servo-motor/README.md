# 🕹️ Steering Servo (MG996R)
The MG996R is a high-torque digital servo that controls the robot's Ackermann steering mechanism. Based on distance readings and navigation decisions from the Arduino, it adjusts the angle of the front wheels to keep the robot on track and execute turns.

It operates at 4.8–7.2V and is controlled via a standard PWM signal from the Arduino.
